# LLMエージェント自作講座（全12回）— Note 記事用教材

プログラミング経験者（Python は読めるがエージェントは初めて、という人）向けに、AI エージェントを **フレームワークなしでゼロから自作して理解する** 講座教材です。LangChain などのフレームワークは一切使わず、Python 標準ライブラリ + urllib で Ollama の HTTP API を直接叩き、「エージェントはただの while ループ」という実感から出発して、道具・記憶・計画・マルチエージェントまで自分の手で組み上げます。

合言葉は **「エージェントはただの while ループ」**。ブラックボックスを開けて、なぜ動くかを仕組みから理解する方針です。

## この講座の独自色

1. **フレームワーク不使用** — LangChain 等は仕組みを隠すため使わない。標準ライブラリだけで全部品を自作する
2. **ローカル小型モデルで完走** — Ollama + 小型モデルで API 課金ゼロ。何度失敗しても財布が痛まないので、試行錯誤そのものを学びにできる
3. **小型モデルの失敗を隠さない** — 巨大モデルなら通る指示が小型モデルでは崩れる。その崩れ方と付き合い方（出力形式の設計、緩い解析、評価セット）を実測つきで教材にする
4. **認知のループとして読む** — エージェントの 観察→判断→行動 のループを、知覚→判断→運動という認知のループと重ねて解説する。各回に「ヒトの側から見ると」という短いコラムを置く
5. **卒業制作は「自分の Mac で働く実用エージェント」** — 動くおもちゃではなく、自分のフォルダを監視して日報を書く小さな当直エージェントを作って卒業する

- 第4部 応用編（第10〜12回）：小型モデルの現実と付き合い、実用品を作って卒業

## 実行環境

- Python 3.10+（追加パッケージ不要。標準ライブラリのみ）
- Ollama（無料・ローカル実行）
- モデル: `gemma4:e4b` を基準に解説（tools 対応・約10GB）。より軽い/重い代替も各回で案内
- 埋め込みモデル（第8回のみ）: `bge-m3`
- 対象マシン: メモリ 16GB 以上の Mac / Linux / Windows（WSL2）
