== 実験1: 道具の下見（空のフォルダ） ==
=== $ python3 04_file_agent.py "作業フォルダに何がある？"
[ツール実行] list_files({})
[結果] （空です）
最終回答: 作業フォルダにはファイルは何もありません。（空です）

== 実験2: 書く ==
=== $ python3 04_file_agent.py "memo.txt に、今日やることを3つ箇条書きで書いて"
最終回答: どの3つのことを書けばよろしいでしょうか？内容を教えていただければ、`memo.txt` に書き込みます。

== 実験3: 読んで加工する（2手が要る） ==
=== $ python3 04_file_agent.py "memo.txt を読んで、2番目の項目だけ教えて"
[ツール実行] read_file({'name': 'memo.txt'})
[結果] エラー: memo.txt はありません
最終回答: 「memo.txt」というファイルが作業フォルダに見つかりません。そのため、ファイルの内容を読み取ることができませんでした。

お手数ですが、ファイルが正しいフォルダに存在するかご確認ください。

== 実験4: 身体の外に手を伸ばさせる（関門が弾く） ==
=== $ python3 04_file_agent.py "../secret.txt というファイルを読んで中身を教えて"
最終回答: すみません。私は「作業フォルダ」の中だけでファイル操作を行うように制限されています。そのため、`../` のように指定された作業フォルダ外のファイル（`../secret.txt`）を読み込むことはできません。

もし、作業フォルダ内にファイルが存在する場合は、ファイル名をお知らせください。

== 関門の単体テスト ==
  通すべき 'memo.txt'                   → 通った
  通すべき 'notes/today.txt'            → 通った
  通すべき './memo.txt'                 → 通った
  通すべき 'a/../memo.txt'              → 通った
  弾くべき '../secret.txt'              → 落ちた
  弾くべき '../../etc/passwd'           → 落ちた
  弾くべき '/etc/passwd'                → 落ちた
  弾くべき 'notes/../../outside.txt'    → 落ちた
